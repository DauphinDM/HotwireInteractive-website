# Website cleanup audit — 29 October 2026

## Scope and sources

Reviewed the homepage, `/websites/`, the team overview, both public profiles, and the 404 page. Keep Hotwire's orange, dark surfaces, and real studio information; typography was subsequently changed to Space Grotesk/Manrope at the owner's request.

Applied these public GitHub resources:

- [Impeccable](https://github.com/pbakaus/impeccable): its [layout guide](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/reference/layout.md) and [technical audit checklist](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/reference/audit.md). Ran the published `impeccable@4.8.0 detect` CLI against all six rendered local pages, with telemetry disabled. No project/global skill installation or agent hooks were added.
- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design): purposeful hierarchy, readable line lengths, specific CTA wording, and removal of redundant decoration/copy.

The detector is supporting evidence, not proof that a design is good or bug-free. Functional and layout regressions are checked separately with Playwright and axe.

## Follow-up: contact service and animation hardening

The site now includes a PHP contact service and finite page/quiz animations. Additional checks found and fixed these edge cases:

- **Request ID conflicts:** duplicate detection now compares a hash of the validated payload, not only its request ID. An edited inquiry cannot be silently acknowledged as an older submission. Native forms repair invalid/conflicting IDs on the retry page.
- **Pending request edits:** the form captures one data snapshot, locks controls before requesting the CSRF token, and unlocks them on success/failure. Asynchronous copying cannot overwrite a sending status.
- **Consent boundaries:** copying locally does not require consent to send personal information; sending still requires it.
- **Keyboard visibility:** focus cancels an active entrance animation on the containing section. Quiz option/result-body motion does not hide its focused heading.
- **Expired briefs:** opening an unavailable or expired quiz transfer now explains what happened instead of silently showing a blank form.
- **PHP source safety:** Vite dev/preview refuses `/api/` requests with a PHP-required 503 response. Server errors cannot be mistaken for successful sends. Deployments still require a properly configured PHP host.
- **Upload handling:** attachments are explicitly rejected, rather than silently ignored.

PHP is tested with both pure validation/transport/rate-limit tests and a real local PHP HTTP server. The mail transport is simulated; no real inquiry or email was sent during verification. Use `npm run test:php` to repeat these checks.

Follow-up verification: **112 browser tests and 8 JavaScript unit tests pass**, alongside the PHP validation, simulated transport, rate-limit, receipt, and HTTP endpoint checks. Live email delivery still requires verification on the deployment host.
